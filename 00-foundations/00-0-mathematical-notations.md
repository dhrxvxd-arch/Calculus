# Mathematical Notations

| Symbols    | Meaning            | Example                    |
| :------    | :------            | :------                    |
| $+$        | addition           | $1 + 1$                    |
| $-$        | subtraction        | $1 - 1$                    |
| $\times$   | product (cross)    | $1 \times 1$               |
| $\cdot$    | product (dot)      | $1 \cdot 1$                |
| $\div$     | division           | $1 \div 1$                 |
| $=$        | equal              | $x = 1$                    |
| $\ne$      | not equal          | $2 \ne 1$                  |
| $\approx$  | approximately      | $\pi \approx \frac{22}{7}$ |
